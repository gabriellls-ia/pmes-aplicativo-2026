# PMES Aplicativo 2026

Aplicativo pessoal de estudos para PMES Soldado Combatente 2026.

## Estrutura
- Português
- Raciocínio Lógico-Matemático
- Geografia
- História

Preserva a estrutura pedagógica construída anteriormente: prioridades, resumos, flashcards, quizzes, pontos fracos, revisão e simulados.

O projeto será disponibilizado como PWA para uso pessoal em iPhone/Android.
